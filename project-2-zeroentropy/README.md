# Project 2 — ZeroEntropy Outbound Engine

**Company:** ZeroEntropy (demo)
**Type:** Automated outbound pipeline
**Tools:** Apollo, Clay, Instantly

---

## Overview

Built a full automated outbound pipeline targeting AI Engineers and ML leads at companies building RAG systems, on behalf of ZeroEntropy — a retrieval accuracy and reranking API for AI teams.

---

## What ZeroEntropy Does

ZeroEntropy is a retrieval accuracy and reranking API built for AI teams. It plugs into any RAG (Retrieval-Augmented Generation) pipeline and improves the quality of search results — fixing the "garbage in, garbage out" problem that makes RAG systems fail in production.

Core value prop: your RAG system works, but answers are hallucinated, irrelevant, or inconsistent. ZeroEntropy fixes retrieval accuracy without requiring a full rebuild.

---

## ICP

| Dimension | Target |
|-----------|--------|
| Geography | United States (primary), United Kingdom, Canada, India |
| Company | Any company building or running an AI system with search/retrieval |
| Size | Any — from YC startups to enterprise; must have an engineer actively building RAG |
| Economic Buyer | CTO, Co-founder & CTO, Head of AI, VP Engineering, Director of AI/ML |
| End User | AI Engineer, ML Engineer, Backend Engineer, Founding Engineer |
| Buying Trigger | RAG pipeline works but not production-ready — retrieval accuracy, latency, or cost problems |

---

## What I Built

- Defined ICP and buying triggers — focused on teams at the "our RAG works but not well enough" stage
- Pulled 25 verified leads from Apollo filtering by title (AI Engineer, ML Engineer, Head of AI) and company signals (hiring for AI roles, LLM tech stack)
- Built a Clay table with AI-personalised emails referencing each lead's specific use case — healthcare retrieval, legal search, customer support agents
- Set up an automated email campaign in Instantly targeting the technical buyer with retrieval accuracy as the hook

## Outreach Approach

Every email was personalised to the lead's specific industry and use case — not generic "AI is the future" copy. The hook was always the same: retrieval accuracy is the last mile problem in RAG, and ZeroEntropy solves it without a rebuild.

---

## Key Learning

> The trigger for ZeroEntropy is very specific — "RAG works, but accuracy or latency isn't production-grade yet." Every touchpoint referenced that exact pain, not generic AI positioning. Specificity is what makes cold outreach feel relevant instead of spammy.
