## What I've Learned

- **Research before tools.** Understand the GTM problem before opening any prospecting tool.
- **Two-sided markets need two ICPs.** Bounty's supply-side and demand-side buyers have different motivations, channels, and triggers.
- **Specificity converts.** Copy that names the exact pain outperforms generic AI pitches.
- **AI can run the whole pipeline.** Project 3 proved Claude Code + Deepline + Lemlist MCP can replace a full manual GTM stack with zero spreadsheets and no copy-paste.
- **QA matters.** Automated quality checks before a campaign prevent bad data reaching real prospects.
